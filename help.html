Playlist Sortings reorders the current IINA playlist by filename, duration, or file size. Use Plugins → Sort Playlist or right-click in the playlist panel.

Filename sorts use the visible name only, with natural number order (episode2 before episode10). Duration uses Spotlight metadata, then ffprobe if it is on your PATH. Size uses the local file size. Items without a usable value (streams, remote URLs) are moved to the end. The currently playing item keeps playing after the playlist is rebuilt.

More information: https://github.com/dotWee/iina-playlist-sortings
